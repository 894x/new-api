# 模型文档维护说明

模型文档支持内置 HTML 和后台在线 HTML 两种来源，不依赖模型广场详情页的数据结构。同一个模型可以配置多种接口形式，每种接口形式都有独立的 HTML、草稿和发布快照。后台发布的同接口在线版本优先于内置版本；删除在线版本后会自动恢复同接口的内置版本。

新增文档时：

1. 在 `documents/` 中新增 `{slug}.html`，文件必须是完整、可独立打开的 HTML 文档。
2. 在 `catalog.json` 的 `documents` 数组中增加对应条目。
3. `model` 必须与模型列表中的 `model_name` 完全一致。
4. 可配置 `interface_key` 和 `interface_name`；未配置时分别使用 `default` 和“默认接口”。同一模型的 `interface_key` 必须唯一。
5. 当前模型文档正文只维护简体中文。

目录页支持根据 `vendor` 和 `category` 筛选。建议使用稳定的类别标识，例如：

- `text`
- `image`
- `audio`
- `video`
- `embedding`
- `rerank`

文档需要同时满足以下两个条件才会公开：

- 系统设置中的“模型文档”模块已启用。
- 模型列表中该模型的“模型文档”开关已启用。

如果模型没有内置文档，也可以从模型列表进入“编辑模型文档”，新增“OpenAI 兼容接口”“原生接口”等接口形式，分别粘贴 HTML、保存草稿并发布。只有内置文档或至少一个已经发布的在线文档存在时，模型列表中的公开开关才可启用。

在线编辑遵循以下发布流程：

1. “保存草稿”只更新后台草稿，不影响当前公开内容。
2. “发布文档”会将最新草稿及其标题、供应商、类别和摘要一起发布。
3. 每个接口形式独立发布；发布一个接口不会影响同模型的其他接口文档。
4. “恢复内置文档”会删除当前接口的在线版本及草稿，并重新使用随程序发布的同接口内置 HTML。
5. 自定义接口形式可以单独删除；没有任何内置版本和已发布接口时，会同时关闭该模型的文档开关。

公开文档页会按模型聚合接口文档，并在内容面板右上角展示接口形式切换器。

站内展示时会统一注入 `document.css`，并同步当前网站主题变量。模型 HTML 只负责正文结构和内容，不要为站内界面新增固定的亮色或暗色配色。
