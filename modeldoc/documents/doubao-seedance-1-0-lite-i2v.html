Volcengine · 视频生成

Seedance 1.0 Lite I2V

doubao-seedance-1-0-lite-i2v

面向图生视频场景的 Seedance Lite 模型，通过 new-api 统一异步视频接口调用。

文本输入图片输入视频输出I2V

Endpoint

POST /v1/video/generations

请求参数

参数 类型 默认值 / 范围 说明
model string doubao-seedance-1-0-lite-i2v 固定为本文模型 ID
prompt string 必填 视频生成提示词
image string 必填 图片 URL 或 Base64 输入
duration number 由上游模型决定 视频时长（秒）
metadata.resolution string 模型默认 输出分辨率等级
metadata.ratio string 16:9 输出宽高比
metadata.content array — 图片、视频、音频等参考媒体
metadata.seed integer 随机 用于复现结果的随机种子
metadata.frames integer — 目标帧数
metadata.camera_fixed boolean false 固定镜头
metadata.watermark boolean false 添加可见水印
metadata.generate_audio boolean false 请求生成同步音频
metadata.draft boolean false 请求草稿模式
metadata.return_last_frame boolean false 请求返回尾帧
metadata.priority integer — 任务优先级
metadata.callback_url string — 异步任务完成回调地址
metadata.service_tier string — 服务等级
metadata.execution_expires_after integer — 任务超时时间（秒）
metadata.tools array — 生成过程中使用的工具
metadata.safety_identifier string — 安全审核上下文标识符

content 元素结构

文本提示词请使用顶层 prompt；此处只列出会作为参考媒体转发的元素。

参数 类型 默认值 / 范围 说明
metadata.content[].type enum 每项必填 image_url、video_url 或 audio_url
metadata.content[].image_url.url string — type=image_url 时填写的图片 URL
metadata.content[].video_url.url string — type=video_url 时填写的视频 URL
metadata.content[].audio_url.url string — type=audio_url 时填写的音频 URL
metadata.content[].role string — 可选的内容角色，原样转发给上游

tools 元素结构

参数 类型 默认值 / 范围 说明
metadata.tools[].type string 每项必填 工具类型，例如 web_search

说明

图片会转换为上游 content[].image_url。模型支持的图片格式、尺寸及时长组合以上游实际响应为准。

API 示例

curl --request POST \
  "$NEW_API_BASE_URL/v1/video/generations" \
  --header "Authorization: Bearer $NEW_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "doubao-seedance-1-0-lite-i2v",
    "prompt": "电影感镜头，一只鲸鱼跃出海面",
    "image": "https://example.com/reference.jpg",
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
